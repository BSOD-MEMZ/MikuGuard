# 2026-11-07 — MikuGuard 诞生

## 做了什么

从 `D:\Dev\EntertainingIsland` 的「摄像头安全指示器」拆出独立插件 **MikuGuard**（`D:\Dev\MikuGuard`），
按需求加了三块新东西：可配颜色的指示点组件、摄像头守护设置页（指定设备 + 程序黑白名单）、带操作按钮的 Windows Toast。

## 工程事实

- `net8.0-windows10.0.19041.0`，`ClassIsland.PluginSdk 2.0.0.2`（带 `ExcludeAssets=runtime;native`），`CreateCipx=true`
- **必须 `GenerateAssemblyInfo=false`**，否则手写 AssemblyInfo.cs 会和 obj 里生成的重复报 CS0579
- cipx 产物落在 `cipx\MikuGuard.cipx`（约 87KB）；`TrimCipxInput` 目标把 `Microsoft.Windows.SDK.NET.dll`(24MB)/`WinRT.Runtime.dll`/pdb 在打包前后移出移回
- 构建：`dotnet build MikuGuard.csproj -c Release`
- 部署：`cp -r bin\Release\net8.0-windows10.0.19041.0\* D:\Dev\ClassIsland\data\Plugins\mikuguard.camera-guard\`（部署前关宿主）

## 关键实现决策

- **谁在用摄像头**：读 `HKCU\...\CapabilityAccessManager\ConsentStore\webcam`，`Start>0 && Stop==0` 即占用；桌面程序额外核对同名进程存活，挡掉崩溃留下的脏记录
- **哪台摄像头**：cfgmgr32 枚举接口路径（`{E5323777-...}` 摄像头类 + `{6994AD05-...}` 视频采集类，按 InstanceId 去重）→ 注册表 `Enum\<inst>` 读 FriendlyName；
  占用探测用 DirectShow moniker `BindToObject(IBaseFilter)`，绑失败=被独占。**只在系统记录已有程序在用摄像头时才探**，避免空闲时反复开设备导致 LED 闪
- **Toast 三件套**：AUMID 注册表项 + `CLSID\{...}\LocalServer32` 指向 `ClassIsland.Desktop.exe` + 开始菜单带 `System.AppUserModel.ID` 的 .lnk（WScript.Shell 建壳 + `IPropertyStore` 写 PKEY → 回读校验）
  按钮回调走 `INotificationActivationCallback` + `CoRegisterClassObject`（自实现 IClassFactory，接口不能加 `[ComImport]` 才能自己实现）
- **回退**：Toast 发不出（系统通知关闭/无 AUMID）时自动改置顶小卡片（纯代码构建，`ShowActivated=false` 不抢焦点），三个按钮行为一致
- **关闭摄像头**：SetupAPI `DIF_PROPERTYCHANGE` + `DICS_DISABLE`（需管理员）；失败回退写 ConsentStore `Value=Deny` 撤销该应用权限
- **关闭应用**：桌面按 MainModule 路径（拿不到退回进程名），UWP 用 `GetApplicationUserModelId` 比对包族名前缀

## 坑 / 验证经验

- **独立 exe 探针发不出 Toast**：`ToastNotificationManager.CreateToastNotifier(aumid)` 在独立 console（.NET 8）里一律 `0x80070490`（连系统自带 PowerShell 的 AUMID 也失败），
  但**在 ClassIsland 宿主里正常**（日志出现 `[toast] 已消失：TimedOut` 即真的弹出来了）。别用独立 exe 判死。
- `InitPropVariantFromString` 是 propsys.h 内联函数、**没有导出**，得自己拼 PROPVARIANT（vt=31，指针放偏移 8，`StringToCoTaskMemUni` 分配）
- Win10 发 Toast **必须**有带 AUMID 的开始菜单 lnk，只写注册表不行（19045 实测）
- 沙箱里启动宿主：`bash ... &` 起的进程会随命令结束被回收；要用 `run_in_background` **直接起 `ClassIsland.Desktop.exe`**（`ClassIsland.exe` 只是启动器，立刻退出），宿主才能活到我去看日志
- Detection 端到端验证手法（不碰摄像头）：后台留一个 python 进程 + 手写一条 ConsentStore 记录指向它 → 日志出现「触发告警」+「已消失：TimedOut」
- `History.Remove(tag, aumid)` 在历史为空时会抛异常（消息为空），dismiss 前要先判有没有真的发过
